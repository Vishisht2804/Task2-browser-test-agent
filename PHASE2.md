# Phase 2 — Generic Browser Observer

## Scope implemented

- Structured observation of page URL, title, bounded visible text, frames, and relevant elements.
- Discovery of standard form controls, buttons, links, headings, forms, landmarks, dialogs, explicit ARIA roles, contenteditable elements, and focusable/custom interactive elements.
- Practical accessible-name and label inference using ARIA attributes, associated labels, element text, alt text, and title.
- Recursive traversal of nested **open** Shadow DOM roots.
- Inspection of all attached Playwright frames, including nested iframes and cross-origin frames where the browser has loaded a frame execution context.
- Frame metadata with parent frame ID and nesting depth.
- Visibility, enabled/disabled state, checked state, input type, labels, placeholders, required/read-only state, test IDs, autocomplete, and other safe attributes.
- Password values, other form-control values, and hidden input values are not copied into observations.
- Sensitive query parameters and URL user information are redacted before URLs are exposed in the observation.
- Per-frame element caps and observation warnings.
- Temporary DOM markers that bind discovered IDs to exact nodes.
- `LocatorResolver` for strict, observation-scoped resolution of element IDs.
- `ObservedActionExecutor` for executing constrained actions against discovered IDs, including controls inside nested frames and open Shadow DOM.
- CLI `inspect` command that writes `observation.json` and `page.png` artifacts.
- Integration tests for ordinary controls, nested open Shadow DOM, nested iframes, action execution, stale IDs, redaction, and truncation.

## Run

```bash
python -m pip install -e ".[dev,browser]"
python -m playwright install chromium
python -m pytest
```

Inspect a website:

```bash
browser-agent inspect --url "https://example.com"
```

Print the observation JSON:

```bash
browser-agent inspect --json --url "https://example.com"
```

## Observation and locator lifecycle

1. `BrowserObserver.inspect(page)` removes markers from its previous snapshot.
2. It enumerates the main frame and every attached child frame.
3. In each frame, it walks the document and recursively enters open shadow roots.
4. It generates unique IDs across the complete observation and tags the matching DOM nodes with temporary `data-ba-*` attributes.
5. It returns a `BrowserObservation` containing an `observation_id`, frame inventory, and element inventory.
6. `BrowserObserver.locator_resolver()` returns a resolver tied to that snapshot and its Playwright frame references.
7. `LocatorResolver` only resolves an element when the caller supplies the matching observation ID. A subsequent observation invalidates previous markers.

**Important:** Re-observe after each action that could change the page. Do not cache or reuse element IDs across observations.

## Completion criteria

- The observer discovers controls without site-specific selectors.
- Element IDs are unique across the main page and all inspected frames.
- Nested open Shadow DOM controls can be discovered and resolved.
- Nested iframe controls can be discovered and interacted with.
- Sensitive form values are not included in the observation payload.
- Stale observation IDs are rejected.
- Large pages are bounded by configurable per-frame element limits.
- The full Phase 0–2 test suite passes.

## Known limitations

- Closed Shadow DOM cannot be inspected.
- The observer's accessible-name logic is heuristic and may differ from the browser's full accessibility tree for complex widgets.
- Browser extensions, browser-native UI, and inaccessible or detached frame execution contexts are outside the observer's control.
- A page can mutate after inspection. The resolver detects removed markers, but the agent must re-observe after navigation or meaningful state changes.
- The observer intentionally does not execute JavaScript generated by an LLM.
